Overview

Velocity is a web and mobile-based vehicle rental management system designed to help users browse, reserve, and manage rentals in a streamlined workflow. The project focuses on a clean user experience, responsive layouts, and a practical booking flow for real-world use.

Key Features

  • Vehicle Listings: Browse available vehicles with key details and pricing.

  • Reservation Flow: Reserve a vehicle through a guided booking experience.

  • Responsive UI: Built to work smoothly across desktop and mobile screens.

My Role

As part of this project, my focus was on structuring the UI, organizing the booking flow, and making the interface feel approachable for users. I also handled the overall front-end implementation and the visual presentation of the system.
