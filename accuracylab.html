AccuracyLab

Aim-Training & Typing Game

React Three.js Firebase Vite

Overview

AccuracyLab is a browser-based application focused on the design and development of an event-driven typing and precision aim-training game. It integrates complex keyboard and mouse interactions into a seamless experience to help players improve their mechanical skills, reaction time, and typing accuracy.

Key Features

  • Precision Aim Training: Dynamic targets to improve mouse accuracy and reaction speed.

  • Typing Modules: Event-driven keystroke tracking to monitor WPM and accuracy.

  • Performance Analytics: Real-time statistics calculating hit rates, misses, and response times.

My Role

As the developer of this project, my focus was on architecting an efficient, event-driven loop to handle real-time inputs without input lag. I was responsible for programming the game logic, designing the user interface, and structuring the performance tracking mechanisms.
